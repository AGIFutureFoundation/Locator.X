# The 90-day path, state by state

The companion the roadmap's v1.3 promised: curriculum item **F6 — from curiosity to first
offer** runs the same ninety-day runway everywhere (*calibrate → build flow → close or walk
clean*, matching the in-app guide's §9), but nearly every checkpoint inside it is set by
state law and county practice. This document localizes each phase against the
[state guides](README.md) — same sequence, state inputs.

> Same rules as the rest of this layer: general education, not advice; verify against the
> current statute and local counsel before money moves ([disclaimer](README.md)). The
> phase names are F6's own; the checkpoints below are the state-varying subset.

---

## Days 1–30 — calibrate

*The phase ends with a written buy box whose every line has an edge behind it (F4), in a
jurisdiction whose record you have actually opened.*

| Checkpoint | Where the state sets it |
|------------|--------------------------|
| Pick the jurisdiction and open its record | The state entry names the portal pattern; the [coverage inventories](coverage/README.md) grade what the record can answer where they exist |
| Recompute the tax line as if you owned it | The single most state-shaped number: resets on sale in [CA](../states/pacific.md#california); never resets in [OR](../states/pacific.md#oregon); homestead/ratio flips in [FL](../states/southeast.md#florida), [SC](../states/southeast.md#south-carolina), [ID](../states/mountain-west.md#idaho), [MN](../states/midwest.md#minnesota), [LA](../states/south-central.md#louisiana) |
| Price the insurance line from quotes, not trailing bills | The survival number on the coasts — [LA](../states/south-central.md#louisiana), [FL](../states/southeast.md#florida), CA wildfire |
| Learn the disclosure regime | Caveat-emptor-leaning states ([AL](../states/south-central.md#alabama), [VA](../states/southeast.md#virginia)) shift the whole O/A burden onto your own pull — budget diligence time now |
| Note the state's comp ceiling | Non-disclosure states ([TX](../states/south-central.md#texas), [LA](../states/south-central.md#louisiana), [MT](../states/mountain-west.md#montana), [WY](../states/mountain-west.md#wyoming), NM) cap the valuation gate — your buy box leans on income evidence there, and says so |
| Find the HFA's participating-lender list | The [quick reference](README.md#the-50-state-quick-reference) names every HFA; the list doubles as your first lender directory ([lenders §11](../resources/lenders.md#11-finding-actual-lenders-any-market)) |

## Days 31–60 — build flow

*The phase ends with underwritten candidates and a bench (F6's "six people before one
offer"), sourced from channels whose mechanics you have read in statute, not folklore.*

| Checkpoint | Where the state sets it |
|------------|--------------------------|
| Choose distress channels by their actual mechanics | The quick reference's tax-system column: lien states are yield-first ([NJ's 18%](../states/northeast.md#new-jersey), [NE round-robin](../states/midwest.md#nebraska)); redeemable-deed states price an option ([TX 25%/6mo](../states/south-central.md#texas), [GA 20%/1yr](../states/southeast.md#georgia)); terminal-deed states ([UT](../states/mountain-west.md#utah), [CA](../states/pacific.md#california), [WA](../states/pacific.md#washington)) transfer clean title day one |
| Read the foreclosure clock into your pipeline math | Judicial states ([NY](../states/northeast.md#new-york), [NJ](../states/northeast.md#new-jersey), [FL](../states/southeast.md#florida), [IL](../states/midwest.md#illinois)) mean the docket *is* the pipeline, months out; first-Tuesday states ([GA](../states/southeast.md#georgia), [TX](../states/south-central.md#texas)) give it a metronome |
| Match deal shape to money | The [matching matrix](../resources/lenders.md#9-the-matching-matrix), then [§10's state adjustments](../resources/lenders.md#10-how-the-state-changes-the-terms) — the same bridge deal prices differently across a judicial line |
| Check the subsidy layer once, in order | County consolidated plan → HFA/QAP → direct federal ([the routing](../resources/federal-programs.md#8-how-federal-money-reaches-a-deal)); a ruled-out program is a memo line, not wasted time |
| Build the bench to the state's closing custom | Attorney states ([GA](../states/southeast.md#georgia), [SC](../states/southeast.md#south-carolina), [NC](../states/southeast.md#north-carolina), [CT](../states/northeast.md#connecticut), MA) vs escrow/title states ([CA](../states/pacific.md#california), [AZ](../states/mountain-west.md#arizona), [UT](../states/mountain-west.md#utah), [WA](../states/pacific.md#washington)) — E2's relationship map has different seats |

## Days 61–90 — close or walk clean

*The phase ends with a written offer and a decision memo citing state sources with pull
dates (gate R) — or a clean walk recorded the same way.*

| Checkpoint | Where the state sets it |
|------------|--------------------------|
| Inspect for the **regional big four** | The in-app guide's list (foundation, soft-story, knob-and-tube, sewer lateral) is California's. Localize it: Gulf coast — roof age/wind mitigation, flood elevation, termites, drainage ([LA](../states/south-central.md#louisiana), [FL](../states/southeast.md#florida)); freeze belt — foundation/basement water, sewer laterals, galvanized/lead supply, heating plant ([Midwest](../states/midwest.md)); mountain west — septic/wells, water rights on anything rural ([guides](../states/mountain-west.md)) |
| Confirm the rent regime on the actual unit | [NY HSTPA](../states/northeast.md#new-york), [CA AB 1482 + local](../states/pacific.md#california), [OR SB 608](../states/pacific.md#oregon), [DC TOPA](../states/southeast.md#district-of-columbia) — a regulated roll is a different asset |
| Know what "won" means before you bid | [NC's upset-bid window](../states/southeast.md#north-carolina) reopens on every raise; [MI](../states/midwest.md#michigan)/[MN](../states/midwest.md#minnesota) redemption delays possession; a "sold" that isn't final yet is gate R's classic certainty error |
| Put transfer/recordation tax in the offer math, both directions | Zero in [TX](../states/south-central.md#texas)/[MO](../states/midwest.md#missouri)/[IN](../states/midwest.md#indiana)-class states; ~4% combined in [DE](../states/southeast.md#delaware); graduated in [WA](../states/pacific.md#washington); NYC's stack in [NY](../states/northeast.md#new-york) |
| Close in the state's actual form | Attorney opinion + abstract states ([IA](../states/midwest.md#iowa), [OK](../states/south-central.md#oklahoma)) carry different title costs; [LA's authentic act](../states/south-central.md#louisiana) and community-property rules shape the signing table |
| Write the memo before the outcome grades it | Sources + pull dates per row; **unknown** where the state's record cannot answer — the state entry told you where that would be on day 1 |

## Four archetypes — how the same 90 days feel different

| Archetype (examples) | What stretches | What compresses |
|----------------------|----------------|-----------------|
| Judicial + lien state ([NJ](../states/northeast.md#new-jersey), [IL](../states/midwest.md#illinois)) | Distress-to-deed timelines (years); day 31–60 pipeline work shifts to pre-foreclosure relationships | Record access (MOD-IV, Cook's portals) — day 1–30 runs fast |
| Nonjudicial + redeemable deed ([GA](../states/southeast.md#georgia), [TX](../states/south-central.md#texas)) | Nothing — the clock is the fastest in the country; your diligence must keep up with first Tuesday | The 61–90 phase can genuinely close in-window; model the redemption premium exactly |
| Escrow West, terminal tax deeds ([AZ](../states/mountain-west.md#arizona), [UT](../states/mountain-west.md#utah)) | Water/septic diligence on anything rural | Title seasoning — terminal deeds and clean escrow custom |
| Town-record New England ([CT](../states/northeast.md#connecticut), [VT](../states/northeast.md#vermont)) | Day 1–30: the record is town-by-town, graded per town; entitlement (VT Act 250) dominates outlook | The market is small enough to hold the whole buy box in view |
